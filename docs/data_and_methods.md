# 数据、变量与估计口径

| 数据源 | 用途 | 核心标识与频率 |
|---|---|---|
| DealScan | 合同利差、期限、用途、担保、贷款行角色 | deal / tranche / lender；贷款发起日期 |
| FDIC Call Reports | 银行资产、资本、存款和未保险存款 | RSSD；季度 |
| FDIC Summary of Deposits | 分支机构存款及县域集中度 | 分支机构、银行、县；年度 |
| Compustat | 借款人财务报表、杠杆和盈利能力 | GVKEY；季度 |
| CRSP / CCM | 市值、波动率及证券—企业衔接 | PERMNO / GVKEY；市场数据 |
| FRED 与 JK 冲击文件 | 政策利率、宏观控制和高频政策冲击 | 按季度对齐 |

## 关键变量

- 因变量：`ln_spread_bps_dep`，all-in drawn spread 的自然对数，要求利差为正。按分析脚本优先使用 `spread_bps_lender_strict`，再使用原有回退字段。
- 存款竞争：`hhi_t` 经标准化得到 `hhi_std_y`。县域 HHI 为存款份额平方和，银行层面按其存款地域分布加权。
- 借款人风险：`pd_naive_bs2008_pit` 经标准化得到 `risk_p_naive_z`。BS 指 Bharath–Shumway。
- 货币政策：`dffr_l1` 为季度政策利率变化的滞后值；`jk_mp_l1` 为滞后 JK 冲击。
- 未保险存款：`RCON5597 / RCON2200`。脚本206在 2006—2024 年银行季度记录上形成银行年度均值，再以估计面板中的不重复银行年度计算中位数（0.443383）。该分组并非按每条贷款观测加权计算中位数。

## 样本和时间匹配

主分析保留美国非金融借款人、广义牵头行以及 2001—2024 年记录，并按变量完整性和固定效应估计的样本规则筛选。不同固定效应及 JK 冲击可用性产生不同有效样本。

清洗阶段、标准化阶段、完整案例筛选及固定效应单例剔除是不同步骤。标准化均值和标准差在脚本208的筛选顺序中确定，不能从最终估计样本重新标准化后期待完全相同的系数。

匹配代码保留日期窗口、银行后继关系和匹配诊断。部分历史合并允许前向报表回退，SOD 年度记录也不等于实时可获得的信息集；本项目不宣称整个样本是严格无前视偏差的交易回测。PiT 风险导出器依赖已构造的发起日风险数据，不能替代从底层输入生成该数据的完整过程。

## 估计

`log(spread) = beta × HHI_z × MP_lag × PD_z + 全部低阶项 + 控制变量 + 固定效应 + 误差`

主表比较借款人×年份、借款人×年份加银行×年份、借款人×年份加银行×企业三种固定效应。JK 稳健性使用第二种。未保险存款分析同时保留子样本估计和 pooled fully interacted Wald 检验，两者的标准误口径不可互换。

## 数据取得与分发

DealScan、Compustat、CRSP 及相关授权链接表需要相应数据库权限，通常通过机构 WRDS 或数据供应商获得。本仓库不含这些数据库的原始数据、逐条衍生面板、匹配记录或账户凭证。公开监管数据仍需按各提供方的获取方式和版本要求准备。README 中的汇总数字仅用于介绍论文发现，不附带回归输出文件。
